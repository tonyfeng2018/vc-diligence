## ✅ 失败案例的启示

### 为什么这个项目"看起来好"但不应该投？

| 表面亮点 | 深层问题 |
|---------|---------|
| "10万用户" | 无法验证，可能是"注册量"而非"活跃用户" |
| "30家医院合作" | 无合同/无公告，大概率是"意向合作"而非实际落地 |
| "7000亿市场" | 市场大不等于你能吃到，赛道已是巨头格局 |
| "AI问诊创新" | 实为规则引擎，无NLP/ML壁垒 |
| "创始人连续创业" | DoX信息存疑，无法核实真实性 |

### Red Flags识别三步法

```
第一步：找最大变量 → 本案例：创始人DoX
         ↓
第二步：验证核心数据 → 本案例：Traction数据无法核实
         ↓
第三步：判断估值合理性 → 本案例：PS 50x，严重偏高
         ↓
结论：触发2个致命Red Flag → 直接否决
```
