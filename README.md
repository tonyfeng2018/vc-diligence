# VC Research Skills

投资尽调研究智能体 — 帮助投资人和分析师在30分钟内快速完成一个项目的初步尽调。

> **当前版本**：v2（2026-04-02）  
> **适用场景**：VC尽调 / 竞品分析 / 投资建议 / 财务验证 / 股票分析

---

## 🎯 项目介绍

这是一个基于 AI 的投资尽调 Skills，帮助投资人在**30分钟内**系统性分析一个项目是否值得投资。

核心方法论来自顶级VC（红杉、高瓴、IDG），输出结构化的八维评估报告 + 竞品 Feature Matrix + 投资建议。

---

## 📊 核心功能

| 功能 | 说明 |
|------|------|
| **八维评估体系** | 团队/市场/产品/商业/竞争/财务/风险/时机 |
| **竞品 Feature Matrix** | 6个竞品全覆盖（功能/定价/市场份额/优劣势/差评痛点）|
| **并行搜索6项强制规则** | 融资/创始人背景/市场规模/竞品/用户评价/监管政策 |
| **SWOT + 关键假设清单** | 投资亮点/风险/退出路径 |
| **赛道分析模式** | 市场规模 + 玩家图谱 + 融资事件 + 结构性机会 |
| **股票/二级市场分析** | 实时股价 + 估值分析 + 投资建议 |
| **搜索失败透明处理** | 缺失数据标注[待验证]，提供根本解决方案 |

## 🚀 快速开始

### 使用示例

```
在 OpenClaw / Claude Code 中发送：

帮我分析一下这个项目：MiniMax，靠谱吗？
帮我看看AI教育赛道，现在还能不能投
帮我看看小米股票，现在值得买吗？
```

### 输出内容

1. **八维评分**：团队/市场/产品/商业/竞争/财务/风险/时机
2. **竞品 Feature Matrix**：6个竞品对比
3. **投资亮点 + 风险点**：各Top 3
4. **SWOT 分析**：一句话总结
5. **估值分析**：合理性判断
6. **投资建议**：建议投资/谨慎投资/不建议
7. **下一步尽调动作**：带时间/平台/具体操作
8. **完整报告**：自动存档到 `memory/` 目录

## 🔑 核心设计原则

1. **数据驱动** — 每个评分必须有量化依据，无法量化则标注[待验证]
2. **诚实比完整更重要** — 宁可承认数据缺失，也不要假装有数据
3. **风险比亮点重要** — 找不投的理由比找投的理由更关键
4. **验证方式比数据更重要** — 用户拿着"待验证"标注可以去自行核实
5. **框架是下限，洞察是价值** — 结构化输出是基础，深度判断才是核心

## ⚠️ 数据说明

本项目中的报告默认依赖外部搜索工具获取实时数据。

当搜索工具无法访问时，所有量化数据会标注 `[待验证]`，并提供具体验证平台（官网/报告名称/搜索关键词），确保可追溯和可补充。
