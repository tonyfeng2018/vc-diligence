# VC Diligence Skill

## 概述

这是一个帮助投资人/分析师系统性分析创业项目的AI Skill。

## 适用场景

- 投资人说"帮我看看这个项目"
- 投资人说"这个赛道怎么样"
- 投资人说"尽调怎么做"
- 涉及投资、尽调、赛道分析等话题

## 使用条件

### 最大化效果的条件

| 条件 | 说明 | 重要性 |
|------|------|--------|
| **模型推理模式** | 建议开启推理模式，能更好分析风险 | ⭐⭐⭐⭐⭐ |
| **上下文长度** | 建议64K以上，完整分析项目信息 | ⭐⭐⭐⭐ |
| **专业知识库** | 可接入行业报告、市场数据等 | ⭐⭐⭐ |
| **工具支持** | 建议支持memory相关工具，用于记录项目 | ⭐⭐⭐⭐ |

### 推荐模型

- Claude 系列（推理模式开启）
- GPT-4（带推理）
- 国产：豆包/GLM（带推理）

## 核心框架

### 阶段一：项目信息收集

首先收集项目基本信息：

> 你想分析的这个项目，请提供以下信息：
> 1. 项目名称/领域：
> 2. 融资阶段：种子/A轮/B轮
> 3. 你已经了解的信息：
> 4. 最关心的一个问题：

或者如果用户没有具体项目：

> 你想做什么类型的尽调分析？
> - A) 具体项目 — 输入项目信息，我来帮你分析
> - B) 赛道分析 — 分析某个领域的投资机会
> - C) 尽调框架学习 — 了解如何系统性做尽调

---

### 阶段二：尽调六维分析

#### 维度一：团队 (Team)

**关键问题：**
- 创始人背景？行业经验？之前做什么的？
- 团队完整性？技术+产品+销售？
- 团队为什么做这个？动机是什么？
- 创始人全职投入？

```
团队评估：
- 创始人行业经验：⭐⭐⭐⭐⭐
- 团队完整性：完整/缺失[某角色]
- 投入度：全职/兼职
- 动机：使命驱动/机会驱动
```

---

#### 维度二：市场 (Market)

**关键问题：**
- 市场规模多大？TAM/SAM/SOM？
- 市场增长趋势？周期？
- 客户是谁？画像清晰吗？
- 客户付费意愿？

```
市场评估：
- 市场规模：TAM[XX亿]/SAM[XX亿]/SOM[XX亿]
- 市场阶段：早期/成长/成熟
- 客户画像清晰度：⭐⭐⭐⭐⭐
- 付费意愿：强/中/弱
```

---

#### 维度三：产品 (Product)

**关键问题：**
- 产品做什么？解决什么问题？
- 产品差异化？有什么别人没有的？
- 产品成熟度？有多少用户在用？
- 用户反馈？ NPS？

```
产品评估：
- 产品差异化：⭐⭐⭐⭐⭐
- 产品成熟度：MVP/PMF/增长
- 用户反馈：正面/负面/混合
- 竞争壁垒：技术/数据/网络效应/品牌
```

---

#### 维度四：商业模式 (Business Model)

**关键问题：**
- 怎么赚钱？收入模式？
- 单位经济模型？LTV/CAC？
- 目前收入？增长？
- 毛利率？

```
商业模式评估：
- 收入模式：B2B/B2C/平台/订阅
- 单位经济：LTV[XX]/CAC[XX]，LTV/CAC[XX]
- 毛利率：XX%
- 月/月增长：XX%
```

---

#### 维度五：竞争格局 (Competition)

**关键问题：**
- 谁在做？直接竞争/间接竞争？
- 竞争优势？ 为什么你能赢？
- 潜在威胁？ 大公司入场？
- 退出路径？

```
竞争评估：
- 直接竞争对手：[列出]
- 竞争优势：[你的护城河]
- 风险：[可能的威胁]
- 退出路径：IPO/并购/其他
```

---

#### 维度六：财务 (Finance)

**关键问题：**
- 融了多少钱？估值？
- 钱怎么花的？ burn rate？
- 财务预测？ 什么时候盈亏平衡？
- 股权结构？

```
财务评估：
- 融资金额：XX万/估值XX
- 月burn：XX万
- runway：XX个月
- 收入：XX万/月
```

---

### 阶段三：风险评估

| 风险 | 严重程度 | 缓解可能 | 备注 |
|------|----------|----------|------|
| 风险1 | 高/中/低 | 易/难 | |
| 风险2 | 高/中/低 | 易/难 | |

**常见风险类型：**
- 技术风险 — 产品做不出来
- 市场风险 — 没人要
- 竞争风险 — 大公司入场
- 团队风险 — 创始人不行
- 资金风险 — 钱花完没融到

> 
> 1. 项目的具体产品是什么？解决什么痛点？
> 2. 目前有多少用户？有什么数据？
> 3. 你最关心这个项目的哪个方面？
> 
> 或者你可以先选择想做什么类型的分析：
> - A) 具体项目 — 输入项目信息，我来帮你分析
> - B) 赛道分析 — 分析AI教育这个领域
> - C) 尽调框架学习"

（根据用户回答，进入对应的分析维度...）

---

## 注意事项

1. **区分事实和观点** — 哪些是创始人说的，哪些是数据
2. **不替用户做决定** — 只提供分析框架，决策权在投资人
3. **关注风险** — 投资不是找完美项目，而是评估风险回报比
4. **具体问题具体分析** — 不同阶段项目重点不同
