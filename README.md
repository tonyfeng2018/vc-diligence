## 🚨 Red Flags 风险等级

| 等级 | 标记 | 含义 | 行动 |
|------|------|------|------|
| 致命 | 🔴致命 | 直接导致投资失败 | 否决 |
| 高风险 | 🔴高 | 显著风险，需重点跟踪 | 降低仓位/设置止损 |
| 中风险 | 🟡中 | 一般风险，影响有限 | 保持关注 |
| 低风险 | 🟢低 | 可忽略 | 正常投资 |

## 📁 报告模板

每份报告包含以下固定章节：

```
1. 核心结论（评分 + 估值 + 建议）
2. 7维评分表（带权重和加权分）
3. 竞品矩阵（Mermaid表格）
4. Red Flags 一览（含风险等级）
5. 投资决策矩阵（含条件触发）
6. Pitch Deck摘要（如适用）
7. 数据可信度评分
8. 下一步检查清单
```

## 🔧 使用方式

### 1. 初始化分析
```
告诉我[项目名称]，融资阶段[天使/种子/A轮/二级市场]
```

### 2. 完整尽调
1. 强制6项并行搜索
2. 7维深度分析
3. Red Flags风险识别
4. 投资决策矩阵
5. 检查清单

### 3. 报告输出
自动保存至：`memory/vc-diligence-YYYY-MM-DD-项目名-v3.x.md`
